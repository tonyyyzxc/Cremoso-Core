## Public endpoints

### 1. POST `/api/auth/login`

- **Access:** Public
- **Middleware:** `loginRateLimit` (10 requests / 15 minutes / IP)
- **Request fields:**

| Field | Type | Required | Source |
| --- | --- | --- | --- |
| `identifier` | string | optional (falls back to `email`) | body |
| `email` | string | optional (used when `identifier` is absent) | body |
| `password` | string | required | body |
| `recaptchaToken` | string | required only when reCAPTCHA is enabled | body |

- **Response codes:**

| Code | Message | When it happens |
| --- | --- | --- |
| 400 | `Username/email and password are required.` | `identifier`/`email` or `password` is empty |
| 503 | `reCAPTCHA is not configured on the server.` | reCAPTCHA is enabled but no secret key is stored |
| 400 | `Please complete the reCAPTCHA check.` | reCAPTCHA is enabled and no token was sent |
| 401 | `reCAPTCHA verification failed. Please try again.` | Google's siteverify rejects the token |
| 401 | `Email or password is incorrect.` | User not found or password mismatch |
| 403 | `This account is not active.` | User status is not `active` |
| 500 | `Unable to sign in.` | Any unhandled error (including reCAPTCHA request failure) |

- **Success response:** `200` — `{ token: string, user: { id, name, username, office, email, role, isSuperAdmin, status } }`
- **Source:** `server/routes/auth.js:27`; `server/controllers/authController.js:105-213`
